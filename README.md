# বাজার দর (Bazar Dor)

চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার আজকের বাজার দর, দামের ওঠানামা এবং বাজারভিত্তিক তুলনা এক জায়গায় দেখার একটি ওয়েব অ্যাপ।

# ব্যবহৃত প্রযুক্তি

১. Next.js (App Router)

২. TypeScript

৩. Tailwind CSS

৪. DaisyUI

৫. Better Auth (ইমেইল-পাসওয়ার্ড, Google, GitHub)

৬. MongoDB

৭. react-hot-toast

# প্রধান ফিচার

১. আজ দাম সবচেয়ে বেশি বেড়েছে ও কমেছে এমন শীর্ষ ৬টি পণ্য এবং সব পণ্যের তালিকা 

২. বাংলা তারিখসহ Navbar এবং পণ্যের দামের ticker।

৩. বিভাগ অনুযায়ী পণ্য দেখা এবং দাম অনুযায়ী সাজানো (sort)।

৪.  পণ্যের বিস্তারিত পাতা: সর্বনিম্ন, সর্বোচ্চ ও গড় দাম এবং বাজারভিত্তিক দামের টেবিল।

৫. সাইন আপ ও সাইন ইন (ইমেইল, Google, GitHub), toast এবং প্রোফাইলে নাম আপডেট ।
